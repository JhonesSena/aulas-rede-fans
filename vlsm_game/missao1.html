🏆 Pontos: 0

💡 O que é um BIT?

Um bit é a menor unidade de informação que existe no computador. Ele só pode ter 2 valores:

0

DESLIGADO

1

LIGADO

🔌 Analogia do interruptor

Pensa numa lâmpada:

  • 💡 Apagada = 0
  • 💡 Acesa = 1

Um bit é exatamente isso: ligado ou desligado. Não existe meio-termo.

📦 E vários bits juntos?

Quando juntamos bits, cada um vale o dobro do anterior:

4
0
2
0
1
0

Com 3 bits, você consegue representar 8 valores diferentes (000, 001, 010, ..., 111).

🎯 Em resumo:

  • 1 bit → 2 valores (0 ou 1)
  • 2 bits → 4 valores (00, 01, 10, 11)
  • 3 bits → 8 valores
  • 8 bits → 256 valores (é por isso que o IP vai até 255!)

🌐 Por que o IP vai só até 255?

Um endereço IP é formado por 4 números separados por pontos:

192 . 168 . 1 . 50

Cada um desses números é um byte (8 bits). E 8 bits só conseguem representar 256 valores (de 0 a 255).

🧮 A conta:

Quando todos os bits estão ligados:

128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255

E 0 a 255 são 256 valores possíveis. Por isso o IP nunca passa disso.

🎯 Conexão com máscaras

Quando você vê uma máscara como 255.255.255.0, está vendo:

  • 255 = 8 bits ligados (11111111)
  • 0 = 8 bits desligados (00000000)

Ou seja: a máscara 255.255.255.0 tem 24 bits ligados → é o famoso /24!

🧠 Por que /26?

Porque 26 bits ficam ligados na máscara, sobrando 6 bits pra hosts (32 − 26 = 6):

2⁶ = 64 endereços totais → 62 utilizáveis
