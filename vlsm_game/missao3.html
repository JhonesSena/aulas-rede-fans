📚 Como funciona o VLSM?

VLSM (Variable Length Subnet Mask) é a técnica de dividir uma rede em sub-redes de tamanhos diferentes, aproveitando melhor os endereços IP.

  • 📏 Fórmula: 2^n − 2 ≥ hosts (o −2 é rede + broadcast)
  • 📊 Ordem: sempre do maior setor pro menor
  • 🎯 Máscaras comuns: /25=126, /26=62, /27=30, /28=14, /29=6, /30=2
  • 🍕 Cada pizza = 1 rede /24 (256 endereços)
  • 🔢 Rede: primeiro IP do bloco (todos bits host = 0)
  • 📢 Broadcast: último IP do bloco (todos bits host = 1)

Exemplo: 60 hosts → precisa de 62 → 2⁶ = 64 → máscara /26.
