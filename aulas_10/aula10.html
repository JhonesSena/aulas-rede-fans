BASE 02

A linguagem das máquinas e o cálculo de redes

A Base de Tudo

No mundo da computação e das redes, não contamos de 10 em 10.

Contamos usando apenas **dois estados**:
LIGADO (1) e DESLIGADO (0).

Por isso a base é 2!

A Regra de Ouro

2n − 2 ≥ HOSTS

O que significa o "-2"?

Você sempre precisa subtrair dois endereços obrigatórios que não podem ser usados por dispositivos:

ENDEREÇO DE REDE O 1º IP do bloco
BROADCAST O Último IP do bloco
Onde aplicamos?

Essa fórmula é utilizada no cálculo de sub-redes IP (IPv4) para determinar quantos hosts válidos podem ser atribuídos a uma determinada rede.

Desmembrando a Fórmula

Aqui está a explicação detalhada de cada termo:

  • 2ⁿ : Representa o número total de combinações binárias possíveis com os bits de host disponíveis (n).
  • - 2 : Subtrai os dois endereços obrigatórios:
    • Endereço de Rede: O primeiro endereço da sub-rede (identifica a própria rede).
    • Endereço de Broadcast: O último endereço da sub-rede (usado para enviar dados a todos os hosts).
  • ≥ hosts : O resultado deve ser maior ou igual à quantidade de dispositivos (computadores, roteadores, impressoras) que você precisa conectar nessa sub-rede.
Mão na Massa

EXEMPLO PRÁTICO

Se você precisa de uma rede que comporte 30 hosts:

  • Aplicamos a fórmula: 2ⁿ - 2 ≥ 30
  • Somamos 2 em ambos os lados: 2ⁿ ≥ 32
  • Encontramos o valor de n: Como 2⁵ = 32, precisamos de no mínimo n = 5 bits reservados para os hosts.
Para não esquecer mais

A ANALOGIA DO ESTACIONAMENTO

Imagine que você vai construir um estacionamento para carros.

Cada vaga precisa de um número de identificação em formato de placa.

O número de "bits" (n) representa justamente o tamanho dessa placa de identificação. Quanto maior a placa, mais vagas (hosts) podem ser numeradas!

O "pedágio" obrigatório

POR QUE SUBTRAIR 2?

Em qualquer estacionamento (sub-rede), você não pode usar todas as vagas para os carros dos clientes. Duas vagas têm funções especiais e fixas:

  • A vaga da Entrada (Endereço de Rede): Serve apenas para identificar qual é aquele estacionamento. Nenhum carro pode estacionar nela.
  • A vaga do Alto-falante (Broadcast): Serve para gritar um aviso para todo mundo ao mesmo tempo. Também não pode ter carro parado nela.

Por isso, se você cria 32 vagas, você obrigatoriamente perde 2. Sobram 30 vagas reais para os carros (hosts).

Testando o tamanho da placa

A MISSÃO DOS 30 CARROS

Você recebeu a missão de estacionar 30 carros. Qual placa escolher?

  • Placa de 4 dígitos (n=4): Cria 16 vagas. Tirando 2, sobram 14. Não cabem seus 30 carros! ❌
  • Placa de 5 dígitos (n=5): Cria 32 vagas. Tirando 2, sobram 30. Cabe perfeitamente! ✅

Por isso o resultado deu n = 5. Significa que você precisa "reservar" 5 espaços no código binário da sua rede para conseguir criar as vagas necessárias.

Recapitulando

A FÓRMULA DE OURO

Nunca se esqueça, a fórmula é:

2n − 2 ≥ HOSTS

Desvendando a Matemática

O PASSO A PASSO NA FÓRMULA

Passo O que fazer Como fica a fórmula
1 Substituímos a palavra "hosts" pelo número de computadores que precisamos (30). 2ⁿ − 2 ≥ 30
2 Passamos o −2 para o outro lado. Ele muda de sinal e vira uma soma (+2), para descobrirmos o total de vagas brutas que precisamos criar. 2ⁿ ≥ 30 + 2
3 Somamos os valores. 2ⁿ ≥ 32
Testando as potências

COMO RESOLVER O 2ⁿ ≥ 32?

Agora você precisa testar as potências de 2 (ir dobrando o número) até encontrar um resultado que seja maior ou igual a 32:

  • 2¹ = 2 (Não dá)
  • 2² = 4 (Não dá)
  • 2³ = 8 (Não dá)
  • 2⁴ = 16 (Quase, mas não dá)
  • 2⁵ = 32 (Achei! É exatamente igual a 32)

Pronto! Descobrimos que n = 5.

Para consolidar

A PROVA REAL

Se tivéssemos escolhido n = 4:
o resultado seria 16, e 16 - 2 = 14 hosts (faltaria espaço).

Escolhendo n = 5:
temos 32 - 2 = 30 hosts Espaço exato! 🎯

Testando as potências

ENCONTRANDO O BITS (n)

Agora vamos dobrando o número 2 até passar ou dar igual a 102:

  • 2⁵ = 32 (Muito pouco)
  • 2⁶ = 64 (Ainda não dá, 64 é menor que 102)
  • 2⁷ = 128 (Passou de 102! Esse serve)

Pronto! Descobrimos que n = 7.

O próximo passo

MÁSCARA DE REDE USANDO (n)

Como o número de bits (n) que encontramos se transforma na Máscara de Rede?

A regra é simples: o endereço IPv4 total tem 32 bits.

Se você "reservou" n bits para os hosts (carros), o resto fica para a rede (o prefixo /CIDR).

Prefixo = 32 − n

A Arquitetura

A REGRA DOS 32 BITS

O endereço IPv4 completo tem exatamente
32 BITS
no total.

A fórmula do prefixo

A REGRA PARA DESCOBRIR A MÁSCARA

  1. Ache o Prefixo (A barra /): Subtraia o número n de 32.

Prefixo = 32 − n

O Passo 2

A REGRA DO ÚLTIMO BLOCO

  1. Escreva a Máscara: O último bloco da máscara vai ser o número 256 menos o Total de Endereços (2ⁿ).

Último bloco = 256 − 2ⁿ

Juntando as Peças

VAMOS APLICAR NA PRÁTICA

Exemplo de 30 hosts (n = 5):
Lembra que para 30 hosts nós descobrimos que o n = 5 e o total de endereços (2⁵) é 32?

Passo O que fazer Conta Resultado
1 Achar o Prefixo (a barra /) 32 − 5 /27
2 Achar o último bloco da máscara 256 − 32 224

Juntando tudo, a máscara fica: 255.255.255.224 com o prefixo /27.
Se você olhar a sua tabela da imagem, vai ver que a linha do /27 tem exatamente a máscara 255.255.255.224 e entrega 30 hosts usáveis!

Entendendo o Conceito

A ANALOGIA DO TELEFONE

Por que usar o 32 para achar a Barra (Prefixo)?

Todo endereço de internet (IPv4) tem, obrigatoriamente, 32 bits no total. Pense nisso como um número de telefone que tem sempre 32 dígitos.

Esse número de telefone é dividido em duas partes:

  • O DDD: que identifica a sua Rede/Bairro.
  • O Número local: que identifica cada Host/Computador dentro daquele bairro.

O seu valor de n é o tamanho do número local.

Fazendo a Conta

REPARTINDO OS DÍGITOS

Se o telefone inteiro tem 32 dígitos e você descobriu que precisa de 5 dígitos para os computadores (n = 5), quantos dígitos sobram para o DDD (a Rede)?

  • 32 − 5 = 27 dígitos para o DDD.

A barra (/) serve apenas para avisar o computador o tamanho desse DDD. Por isso escrevemos /27. Ela diz: "Dos 32 dígitos possíveis, os primeiros 27 são o DDD".

Se você precisar de 7 dígitos para os computadores (n = 7):

  • 32 − 7 = 25 dígitos para o DDD. Escrevemos /25.
Desmistificando a Máscara

O QUE É O "ÚLTIMO BLOCO"?

Uma máscara de rede inteira sempre tem 4 blocos separados por pontos. Ela começa padrão assim:

255.255.255.X

  • O X é o "último bloco". É ele que muda para fechar o tamanho do estacionamento.
  • No mundo dos computadores, o tamanho máximo absoluto que um bloco desses pode ter é 256 combinações.
Fazendo a Conta

TROCANDO O "X"

Se você descobriu que a sua rede vai ocupar um espaço total de 32 vagas (que é o 2⁵):

Você pega o limite máximo (256) e desconta o tamanho do seu estacionamento (32):

  • 256 − 32 = 224

Aí você troca o X por esse resultado:
255.255.255.224

Mais um Exemplo

AUMENTANDO A REDE

Se a sua rede for maior e ocupar um espaço total de 128 vagas (que é o 2⁷):

Você pega o limite máximo (256) e desconta o tamanho do seu estacionamento (128):

  • 256 − 128 = 128

Aí você troca o X por esse resultado:
255.255.255.128

Para não esquecer

RESUMO DAS REGRAS FIXAS

  • Para achar a Barra (/): Você sempre faz 32 menos o seu n.
    Prefixo = 32 − n
  • Para achar o Final da Máscara: Você sempre faz 256 menos o total de endereços (2ⁿ).
    Último bloco = 256 − 2ⁿ
Próximo Passo

A REGRA DO SALTO

O Tamanho do Pedaço

O seu salto é sempre o Total de Endereços daquela máscara.

Como você descobriu que a máscara /28 termina em 240:

  • Conta do Salto: 256 − 240 = 16.
Atenção Máxima!

A ÚNICA REGRA DE OURO

Organizar do Maior
para o Menor

Quando você tem várias redes (vários estacionamentos) de tamanhos diferentes, você SEMPRE começa calculando a rede que precisa de mais hosts e vai descendo até chegar na rede que precisa de menos.
